# FS25_MapObjectsHider

## DE

Wenn der Mapper andere Pläne hatte als du, musst du nicht mehr direkt Änderungen in der Map machen.

Mit diesem Mod kannst du störende Map-Objekte direkt im Spiel ausblenden. Dazu gehören zum Beispiel Gebäude, Leitplanken, Zäune und viele andere Objekte.

Ausgeblendete Objekte werden im Savegame gespeichert und bleiben dauerhaft unsichtbar, solange sich die Mapstruktur nicht ändert.

Einige Objektarten werden nicht ausgeblendet, sondern entfernt:
- platzierbare Gebäude werden verkauft oder gelöscht
- Bäume werden gelöscht

Gelöschte oder verkaufte Objekte können nicht wiederhergestellt werden.

Nicht alle Objektarten können erkannt oder entfernt werden, zum Beispiel parkende Fahrzeuge.

Der ursprüngliche Mod wurde für den **FS19** von anderen Moddern erstellt.
Mit Erlaubnis der ursprünglichen Autoren habe ich ihn für den **FS22** konvertiert.
Für den **FS25** wurde er von mir vollständig neu aufgesetzt und in Teilen neu geschrieben.

## EN

If the mapper had different plans than you, you no longer need to modify the map itself.

This mod allows you to hide unwanted map objects directly in the game, such as buildings, crash barriers, fences and many other objects.

Hidden objects are stored in the savegame and remain invisible permanently as long as the map structure does not change.

Some object types are removed instead of hidden:
- placeable buildings are sold or deleted
- trees are deleted

Deleted or sold objects cannot be restored.

Not all object types can be detected or removed, for example parked vehicles.

The original mod was created for **FS19** by other modders.
With permission from the original authors, I converted it to **FS22**.
For **FS25**, it was completely rebased and partly rewritten by me.
